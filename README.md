# 좌석 감시 (SeatWatch)

네이버 항공권 검색 주소를 몇 분마다 다시 열어서, 정한 출발 시간대에 좌석이 생기면
**윈도우 알림**과 **휴대폰(ntfy 앱·텔레그램)** 으로 알려 주는 프로그램입니다.
상단의 **국내선 · 국제선** 탭으로 탑승권 목록을 나눠 봅니다(탭 이름 옆 숫자는 노선 수). 탭은 보기만 나누며, 보고 있지 않은 탭의 노선도 계속 감시하고 알립니다. 마지막으로 본 탭은 다음 실행 때 그대로 열립니다.
탑승권 카드를 선택하면 해당 노선의 항공편과 운임을 볼 수 있습니다. 하단의 **조회 화면**(지구본) 버튼에서 감시 중인 WebView2 페이지를, **조회 기록**(시계) 버튼에서 시간별 결과를 확인합니다. 다시 누르거나 **←** 버튼을 누르면 탑승권 목록으로 돌아갑니다.
운임표의 **항공사 · 좌석 등급** 열에서 밑줄이 표시된 이름을 누르면 해당 항공사의 공식 홈페이지가 기본 브라우저에서 열립니다.

## 실행
버튼은 아이콘으로 표시됩니다. 마우스를 올리면 버튼 이름이 나옵니다. **↻** 버튼은 지금 바로 조회합니다.

`app\SeatWatch.exe` 를 실행합니다. `app` 폴더의 DLL 3개가 EXE 옆에 같이 있어야 합니다.

1. 상단의 **＋**(감시 추가) 버튼 → **조건 선택** 탭에서 출발 공항, 도착 공항, 출발 날짜를 고릅니다. 새 검색은 성인 1명 편도 기준입니다. 지금 보고 있는 탭에 따라 국내선 또는 국제선 입력 창이 열립니다.
   국제선은 목록에서 고르거나 공항 코드(예: `NRT`, `BKK`)를 직접 입력합니다. **도쿄 전체**(`TYO`)처럼 도시를 고르면 그 도시의 모든 공항(나리타·하네다)을 함께 봅니다. **직항/경유**(직항만 · 경유 1회까지 · 2회까지), **소요시간 N시간 이내**, **카드 할인 빼고 보기**도 고를 수 있습니다. 항공사 목록에는 국내 항공사와 자주 쓰는 외국 항공사가 나옵니다.
2. 원하는 출발 시간대와 항공사를 선택하고 **감시 추가**를 누릅니다. 시간대가 비어 있으면 하루 전체를 조회하고, 항공사가 **전체**이면 모든 항공사를 감시합니다. 네이버 국내선·국제선 편도 검색 주소가 있으면 **주소 붙여넣기** 탭에서도 등록할 수 있습니다(왕복·다구간 주소는 받지 않음). 등록하면 그 노선의 탭으로 바뀝니다.
   아래쪽 **최대 금액**을 체크하고 금액을 정하면 그 금액 이하(성인 1명 편도 운임)인 좌석만 운임표에 보이고 알림이 옵니다. 네이버 주소에는 금액 조건이 없어서 앱이 조회 결과를 직접 거르며, 두 탭 모두에 적용됩니다. 가격이 내려 기준 안으로 들어온 좌석도 새 좌석으로 알립니다.
3. 휴대폰 알림을 받으려면 상단의 **톱니바퀴**(알림 설정) 버튼에서 ntfy 주제를 입력하고 **종**(시험 알림) 버튼으로 확인한 뒤 **저장**합니다.
   주제 칸 옆 **?** 버튼을 누르면 **안드로이드**·**아이폰** 탭별로 ntfy 앱 설치·구독 방법과 스토어 링크가 나옵니다. 안드로이드는 구독할 때 즉시 전달(Instant delivery)을 켜고 배터리 사용을 '제한 없음'으로 두어야 알림이 늦지 않습니다. 아이폰은 알림 허용과 집중 모드의 허용된 앱을 확인합니다. 같은 창의 **섞기** 버튼으로 남이 짐작하기 어려운 무작위 주제를 만들 수 있습니다. ntfy.sh 주제는 비밀번호가 없어서 이름을 아는 사람은 누구나 알림을 볼 수 있습니다.
4. 텔레그램으로도 받을 수 있습니다. 같은 창의 **텔레그램 봇 토큰** 옆 **?** 버튼에 BotFather로 봇을 만드는 방법이 나옵니다(아이폰·안드로이드 같음). 토큰을 넣고 텔레그램에서 내 봇의 **Start**를 누른 뒤, **채팅 ID** 옆 **돋보기**(찾기) 버튼을 누르면 채팅 ID가 채워집니다. 텔레그램은 봇에게 온 메시지를 24시간만 보관하므로 Start 후 하루 안에 찾아야 합니다.
   ntfy와 텔레그램은 채워 둔 곳마다 보냅니다. 둘 다 채우면 둘 다 받고, 쓰지 않을 쪽은 칸을 비워 두면 됩니다. 시험 알림에서 보내지 못한 곳이 있으면 이유를 바로 보여 주고, 감시 중 실패는 조회 기록에 남습니다. 봇 토큰은 Windows 사용자 계정의 DPAPI로 보호하며 입력창에서도 가립니다. 기존 평문 설정과 정상 백업은 새 버전 첫 실행 때 변환합니다.
5. 창을 닫거나 최소화하면 알림 영역(시계 옆)으로 숨어서 계속 감시합니다.
   끝내려면 알림 영역 아이콘 오른쪽 클릭 → **끝내기**.

- 운임표 아래 **눈**(노선 감시 끄기·켜기) 버튼으로 선택한 노선만 멈출 수 있습니다. 운임표 위 **↗**(네이버 화면 열기) 버튼은 해당 노선을 기본 브라우저에서 엽니다.
- 등록한 노선은 운임표 아래 **연필**(조건 수정) 버튼에서 변경합니다. **휴지통** 버튼은 노선을 삭제합니다. 조건을 바꾸면 새 조건의 첫 정상 조회를 알림 비교 기준으로 삼습니다. 직접 입력한 유효한 시간 범위는 주소로 수정할 수 있습니다. 예전에 저장한 지원 범위 밖의 주소는 목록에 보존하며 자동 조회를 중단합니다.
- 자동 조회가 진행 중이지 않을 때 카드를 두 번 누르면 앱 안에서도 해당 검색 페이지를 열 수 있습니다.
- 카드와 운임표는 활성 노선의 최근 조회가 성공했을 때 좌석과 운임을 표시합니다. 앱 재시작, 감시 중단, 재조회 진행 중, 조회 실패 시에는 해당 상태를 표시하고 이전 운임은 숨깁니다.
- 페이지 이동 실패, 로딩 중인 화면, 판독 오류 때는 이전 알림 기준을 유지합니다. 현재 국내선 페이지는 50개씩 불러옵니다. 50의 배수에서 멈추고 현재 화면의 국내선 행을 모두 읽었으면 `일부 확인`으로 표시합니다. 이때는 조건에 맞는 관측 좌석만 표시·알림하며 보이지 않은 기존 좌석의 소멸은 전체 조회가 성공할 때까지 확정하지 않습니다.
- 노선 감시를 끄거나 삭제하면 진행 중인 해당 조회도 취소합니다. 상단의 **일시정지** 버튼으로 전체 모니터링을 끄면(꺼진 동안에는 **재생** 버튼), 진행 중인 한 항목을 마친 뒤 멈춥니다.
- 휴대폰(ntfy) 알림에는 새 좌석을 파는 항공사의 공식 홈페이지 링크가 붙습니다. 항공사가 한 곳이면 알림을 누를 때 그 홈페이지가 열리고 **네이버에서 보기** 버튼이 붙습니다. 여러 곳이면 알림은 네이버 검색 화면을 열고, 가장 싼 좌석이 있는 항공사부터 최대 3곳의 버튼이 붙습니다. 항공사 사이트는 홈페이지까지만 열리므로 날짜와 노선은 다시 골라야 합니다. 아이폰 ntfy 앱에서 버튼이 보이는지는 시험 알림으로 확인하세요.
- 텔레그램 알림은 누르면 봇 대화방이 열리고, 메시지 아래에 항공사 홈페이지 버튼(싼 좌석 순 최대 4곳)과 **네이버에서 보기** 버튼이 붙습니다.
- 알림은 **지난 조회에 없던 좌석**(출발 시각·항공사·좌석 등급, 국제선은 출발 시각·항공사·직항/경유·도착 시각)이 보일 때만 옵니다. 최대 금액을 정했다면 그보다 비싼 좌석은 없는 것으로 칩니다. 좌석은 있는데 모두 비싸면 `금액 초과 좌석만 N개`로 표시합니다.
- 조회 간격은 최소 2분입니다(너무 자주 열면 네이버가 막을 수 있음).
- **조회 기록**(시계) 화면 위쪽에는 최근 20회 조회의 평균·중간값·가장 느린 소요 시간이 나옵니다. 그 아래 표에는 조회마다 한 줄씩 시각, 노선, 걸린 시간, 단계별 시간(페이지 이동 · 첫 카드 대기 · 스크롤), 시도 횟수, 결과가 쌓이고, 최근 것이 위에 옵니다. 10초 이상 걸린 조회와 확인하지 못한 조회는 주황색으로 표시합니다. 맨 아래에는 `log.txt` 원문이 나오며, 앱을 다시 켜도 이전 기록이 그대로 보입니다.
- 운임표 상태 줄에는 마지막 조회 시도와 소요 시간, 마지막 전체 정상 확인 일시, 이후 연속으로 전체 확인에 실패한 횟수가 표시됩니다. 취소는 실패 횟수에서 제외됩니다.
- 감시 추가 시 **첫 조회에서 발견한 좌석도 알림**을 선택할 수 있습니다. 기본값은 첫 판독을 비교 기준으로만 삼습니다. 알림에는 출발·도착 시각과 운임이 들어갑니다. 휴대폰 전송이 실패하면 해당 채널에서 같은 좌석이 다시 관측될 때 최대 두 번 더 시도합니다. 전송 대기는 재시작 후에도 이어집니다.
- 출발일이 지난 노선은 날짜가 바뀌거나 앱을 다시 열 때 자동으로 감시를 종료하고 목록에 보관합니다. 운임표 아래 **다른 날짜로 노선 복제** 버튼은 새 날짜에 기존 시간대·항공사·금액 조건을 복사합니다.
- 설정은 임시 파일에 쓴 뒤 교체하고 직전 정상본을 settings.json.bak에 보관합니다. 시작할 때 원본을 읽지 못하면 백업을 복구하고 알려 줍니다. 두 파일 모두 읽을 수 없으면 그대로 보존하고 파일 위치를 안내합니다.

### 국제선
- 네이버 국제선 화면에는 출발 시간대·항공사·경유 횟수(1회까지)·소요시간 조건이 없어서, 앱이 하루 전체 목록을 읽고 직접 거릅니다. 고른 조건은 감시 주소에 `depTime0`·`airline`·`maxStops`·`maxHours`로 적어 두고, 네이버를 열 때는 빼고 엽니다(**↗** 버튼, 알림의 **네이버에서 보기**도 같음). 직항만(`isDirect=true`)과 카드 할인 빼기(`cardBenefit=0`)는 네이버 주소 조건이라 그대로 엽니다.
- **카드 할인 빼고 보기**(새 노선 기본값): 어떤 결제수단으로도 낼 수 있는 가격으로 비교합니다. 끄면 네이버 기본 화면처럼 `KB국민 Less go카드(이용실적 충족 시)` 같은 특정 카드 조건 가격이 나오는데, 실측에서 같은 편이 3~4만 원 싸게 보였습니다. 어느 쪽이든 '1만원 할인' 같은 이벤트 할인 전 가격을 씁니다.
- 탑승권에는 시간대 옆에 `직항만 · 10시간 이내 · 카드 할인 제외`처럼 국제선 조건이 붙습니다.
- 도시 검색(서울·도쿄·오사카·삿포로·베이징·뉴욕 전체)은 편마다 공항이 달라서, 운임표의 직항/경유 칸에 `직항 · ICN→HND`처럼 실제 공항이 붙습니다.
- 운임표의 **항공사 · 직항/경유** 열에 `경유 1`처럼 경유 횟수가 나오고, 도착이 다음 날이면 도착 시각에 `(+1일)`이 붙습니다. 여러 항공사를 타는 일정은 `대한항공, 일본항공`처럼 나오며, 항공사 조건에 고른 곳이 하나라도 들어 있으면 감시 대상입니다.
- 네이버가 **동일가 다른 일정**으로 접어 둔 편은 읽지 않습니다. 상태 줄에 `접힌 동일가 일정 N편 미확인`으로 개수를 보여 주므로, 원하는 시각이 그 안에 있을 수 있으면 **↗** 버튼으로 네이버에서 직접 확인하세요.
- 외국 항공사는 공식 홈페이지 주소를 넣지 않았습니다. 알림에는 네이버 링크만 붙습니다.

| `src\FlightSearch.cs` | 네이버 국내선·국제선 검색 주소 읽기·만들기, 항공사 목록 |
