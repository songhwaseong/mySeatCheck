SeatWatch 좌석 감시 · 사용법
==============================

네이버 항공권(국내선)을 몇 분마다 조회해서, 원하는 시간대에 좌석이 생기면
윈도우 알림과 휴대폰(ntfy 앱 또는 텔레그램)으로 알려 주는 프로그램입니다.


[설치]

1. 받은 zip 파일을 오른쪽 클릭 → 속성 → 아래쪽 '차단 해제'에 체크 → 확인.
2. 압축을 풀고 SeatWatch 폴더를 원하는 곳(예: 문서)에 둡니다.
   폴더 안의 SeatWatch.exe 와 dll 파일 3개는 항상 함께 있어야 합니다.
3. SeatWatch.exe 를 실행합니다.
   "Windows의 PC 보호" 파란 창이 뜨면 '추가 정보' → '실행'을 누릅니다.

필요한 환경: 윈도우 10/11 64비트.
윈도우 10에서 조회 화면이 비어 있으면 Microsoft 'WebView2 Runtime'을 설치하세요.
https://developer.microsoft.com/microsoft-edge/webview2/


[감시 추가]

1. 위쪽 ＋ 버튼 → 출발·도착 공항, 날짜, 출발 시간대, 항공사를 고르고 '감시 추가'.
2. 아래쪽 '최대 금액'을 체크하면 그 금액 이하 좌석만 보여 주고 알립니다.
3. 첫 조회는 기본적으로 비교 기준만 잡습니다. 처음부터 알림을 받으려면
   '첫 조회에서 발견한 좌석도 알림'을 선택하세요.
4. 출발일이 지나면 감시가 자동 종료됩니다. '다른 날짜로 노선 복제' 버튼으로
   같은 시간대·항공사·금액 조건을 새 날짜에 복사할 수 있습니다.

버튼 위에 마우스를 올리면 버튼 이름이 나옵니다.


[휴대폰 알림]  위쪽 톱니바퀴(알림 설정) 버튼

- ntfy: 주제 칸 옆 ? 버튼의 안내대로 휴대폰에 ntfy 앱을 설치합니다.
  같은 창의 섞기 버튼으로 나만의 주제를 만드세요.
  다른 사람과 같은 주제를 쓰면 서로의 알림이 섞입니다.
- 텔레그램: 봇 토큰 칸 옆 ? 버튼의 안내대로 BotFather 로 내 봇을 만들고,
  돋보기 버튼으로 채팅 ID를 찾습니다. 봇은 각자 만들어 쓰세요.
- 종 버튼으로 시험 알림을 보내 확인한 뒤 '저장'을 누릅니다.
- 활성화하고 채운 채널로 알립니다. 알림에는 출발·도착 시각과 운임이 들어갑니다.
- 전송이 실패하면 좌석이 다시 확인된 조회에서 해당 채널만 최대 두 번 더 시도합니다.
- 텔레그램 토큰은 현재 Windows 사용자 계정으로 암호화해 저장합니다.


[알아 둘 것]

- 전체 목록 끝을 확인하지 못해도 화면의 50개 단위 행을 모두 판독했다면 '일부 확인'으로 표시합니다.
  확인한 좌석은 알리며 보이지 않은 기존 좌석은 다음 전체 확인까지 비교 기준에 남깁니다.
- 노선 상태에서 마지막 정상 확인 시각과 연속 전체 확인 실패 횟수를 볼 수 있습니다.
- 설정을 저장하면 직전 정상본이 data 폴더의 settings.json.bak에 남습니다.
  원본 손상 시 백업을 복구하고 알려 줍니다.
- 창을 닫아도 시계 옆 알림 영역에 숨어서 계속 감시합니다.
  끝내려면 알림 영역의 SeatWatch 아이콘 오른쪽 클릭 → 끝내기.
- PC가 꺼지거나 절전 모드에 들어가면 감시도 멈춥니다.
- 설정과 조회 기록은 SeatWatch 폴더 안 data 폴더에 저장됩니다.
  이 프로그램을 다른 사람에게 줄 때는 data 폴더를 빼고 주세요.
  (봇 토큰, 알림 주제, 감시 노선 같은 개인 설정이 들어 있습니다.)
- 알림은 참고용입니다. 예약은 항공사나 네이버에서 직접 하세요.
  좌석은 금방 팔릴 수 있습니다.
